# Atlas Canonical Map

**Role:** Master intellectual map of Living Terrain — the editorial source of truth.  
**Not:** A software spec. Not an interface redesign brief.  
**Last updated:** 2026-07-27

Grow Living Terrain by deepening this map. Prefer coherence over volume. Prefer deepening existing concepts before inventing new ones. Nothing should exist in isolation.

When writing is thin, label the gap. Do not invent ideas Chelsea has not already explored.

---

## How to use this document

1. Before writing a new essay — find which concept, question, and journey it strengthens.  
2. Before naming a new concept — check for duplicates and overlaps below.  
3. Before adding a book excerpt to Atlas — confirm it deepens an existing journey.  
4. After publishing — update the relevant rows in this file in the same breath of work.

Companion document: [`LIVING_TERRAIN_ROADMAP.md`](./LIVING_TERRAIN_ROADMAP.md) — what to write next.

## Doctrine

1. **Concepts** hold a canonical definition and a one-line fragment that can stand alone.  
2. **Essays** are scout reports — living inquiry that supports concepts.  
3. **Books** are field journals — gravity beneath concepts, not storefront SKUs.  
4. **Models** clarify relationships already present in the writing.  
5. **Questions** open journeys; journeys never dead-end.  
6. **Chambers** are the interiors of completed investigations (maps hung in The Atlas).  
7. Gaps are **future opportunities**, not invitations to invent philosophy.

4. Consciousness is too broad to use as a primary Atlas journey start — enter through Body, Perception, or Time.
